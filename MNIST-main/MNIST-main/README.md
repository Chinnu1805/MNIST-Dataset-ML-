# MNIST Handwritten Digit Classification

A **CNN-based image classification project** that recognizes handwritten digits (0–9) using the MNIST dataset.

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* CNN
* NumPy
* Matplotlib

## 📌 Project Description

* Developed a CNN model to classify handwritten digits using the MNIST dataset.
* Preprocessed and normalized images before training.
* Trained and evaluated the model on the MNIST dataset.
* Optimized training parameters to improve model performance.
* Achieved approximately **85% test accuracy**.

## 📊 Dataset

* 60,000 training images
* 10,000 testing images
* Image size: **28 × 28 pixels**
* Grayscale handwritten digits from **0 to 9**

## 🔄 Workflow

```text
MNIST Dataset
     ↓
Image Preprocessing
     ↓
CNN Model
     ↓
Model Training
     ↓
Evaluation
     ↓
Digit Prediction
```

## 🚀 How to Run
